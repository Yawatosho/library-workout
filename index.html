ABOUT LIBRARY WORKOUT

体を動かすためにジムへ行くように、頭を動かすために図書館へ。

LIBRARY WORKOUTは、図書館での読書、勉強、棚を見ることなどを気軽に記録して振り返るアプリです。

HOW TO USE

  1. VISITを記録
  2. 必要なら図書館名を入力
  3. その日に行った活動を記録
  4. CALENDAR / STATSで振り返る

DATA & PRIVACY

入力した図書館名や活動記録は、この端末のブラウザ内（localStorage）に保存されます。通常はブラウザを閉じても記録は残り、運営者のサーバーには保存されません。

サイトの利用状況を把握するためGoogle Analyticsを使用しています。ページ閲覧などのアクセス情報がGoogleへ送信される場合がありますが、入力した図書館名や具体的な活動内容をAnalyticsへ送信することはありません。

ブラウザのサイトデータ削除や端末変更などによって記録が失われる場合があります。必要に応じてSTATS画面のExportからJSONファイルとしてバックアップしてください。Exportしたファイルはご自身で管理してください。
